## 2. 项目概况分析
### 核心架构
- **项目名称**：IOSCrmApp (iOS 移动端 CRM 应用)
- **技术栈**：SwiftUI, MVVM/Service 架构
- **代码结构**：
  - `ioscrmapp/`：源码根目录
  - `Modules/`：功能模块化 (AI, Mall, Auth, Video, Billing 等)
  - `Services/`：业务服务层，负责接口联调与逻辑解耦
  - `DesignSystem/`：视觉规范与自定义组件
  - `Core/`：底层核心工具类

### 已识别模块
1. **AI 模块**：智能交互聊天。
2. **商城模块**：商品浏览与购买流程。
3. **认证模块**：登录、注册及权限管理。
4. **财务模块**：账单、充值、卡券及票据系统。
5. **用户中心**：个人资料及勋章系统。
